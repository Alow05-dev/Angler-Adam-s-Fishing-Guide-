# Angler Adam's Fishing Guide

Mobile-first fishing recommendation app for GitHub Pages.

## Upload to GitHub

Upload these files to the root of your repository:

- `index.html`
- `styles.css`
- `main.js`

Then go to **Settings → Pages → Deploy from a branch → main → /(root)**.

No Node.js, npm, server, or database is required.

## Included functionality

- Responsive iPhone-first design
- Trip planner
- Species selector
- Waterbody selector
- Date/time/weather/wind/water inputs
- Recommendation engine
- Top picks / alternatives / techniques / location tips
- Tackle box saved in localStorage
- Saved trips saved in localStorage
- Location permission button
- Species and lake quick selectors
- Bottom navigation


## Trip profile inputs

The planner now factors in:
- Fishing depth
- Shoreline vs. boat
- Baitcasting vs. spinning vs. downrigger vs. fly setup
- Water temperature, clarity, wind, sky, time and target species
